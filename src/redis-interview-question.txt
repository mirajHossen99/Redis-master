what is actually redis?
=> Redis is in memory data store. 
   Keeps data mainly in RAM, read and write operations will be very fast.
   Cache, Rate limiter, Message broker, temp fast layer in front of your normal/main database

Why Redis is use? or Why we need Redis?
=> PostgreSQL --> Permanent Structured data
   Redis -->
   - Speed or temp data?? Redis can be helpfull
   - Caching product list,
   - Count prodcut views
   - Limit how many req a user can make running background jobs
   - Short lived or frequent acessed data
   - Store the data on disk(PostgreSQL) vs Memory(Redis)

----- Caching -----
=> storing the copy of data in a first place so future request can be read very quickly
Reduce database load, Improve response time

----- Cache aside pattern -----
1. Check cache first.
2. If cache has data return it
3. Cache doesn't have data, read from main database then save in cache

------ pub / sub --------
pub --> publish 
sub --> subscribe

subscriber listens and receives the messsages
